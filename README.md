# 🤖 ربات تلگرام چت و همسان‌گزینی ناشناس | Telegram Anonymous Matchmaking Bot

یک پلتفرم مدرن، امن و با عملکرد فوق‌العاده بالا برای اتصال ناشناس کاربران بر اساس معیارهای دلخواه (جنسیت، رده سنی و استان)، مجهز به سیستم اقتصاد سکه، ضداسپم، نظارت هوشمند و پنل مدیریت ادمین.

توسعه‌داده‌شده با **Node.js**، **TypeScript**، فریم‌ورک قدرتمند **grammY**، پایگاه داده رابطه ای **PostgreSQL (Drizzle ORM)** و حافظه سریع **Redis**.

---

## 🌟 ویژگی‌های کلیدی ربات (Key Features)

- 🔒 **ثبت‌نام امن با جنسیت قفل‌شده (Immutable Gender):**
  فرآیند آنبوردینگ ۶ مرحله‌ای (نام، جنسیت، سن، استان، بیوگرافی و عکس). به منظور جلوگیری از هرگونه سوءاستفاده یا تغییر هویت فریب‌کارانه، جنسیت کاربر پس از ثبت اولیه برای همیشه قفل و غیرقابل تغییر می‌ماند.

- ⚡ **موتور تطبیق پیشرفته متقابل (Reciprocal Redis Matchmaking):**
  صف انتظار با مقیاس‌پذیری بالا در Redis. کاربر تنها زمانی با فرد دیگر متصل می‌شود که معیارهای هر دو طرف (سن مجاز، جنسیت هدف و استان) به صورت دوطرفه همخوانی داشته باشند. سیستم دارای قفل ضد مسابقه (Concurrency Mutex Lock) برای جلوگیری از تداخل است.

- 🪙 **اقتصاد سکه و سیستم زیرمجموعه‌گیری (Coin & Referral Economy):**
  - **۱۰ سکه رایگان اولیه** در بدو ورود.
  - **لینک اختصاصی دعوت:** با ورود هر دوست، **۱۵+ سکه** به معرف و **۵+ سکه هدیه** به دوست تعلق می‌گیرد.
  - کسر سکه هوشمند برای جستجوهای هدفمند و ارسال پیام مستقیم.

- 🎁 **گردونه و پاداش روزانه (`/daily`):**
  کاربران هر ۲۴ ساعت یک‌بار می‌توانند پاداش روزانه خود (+۲ سکه) را دریافت کنند تا اشتیاق بازگشت به ربات همیشه بالا بماند.

- 💬 **ارسال پیام ناشناس مستقیم با شناسه کاربری (`/find_id`):**
  به هر کاربر یک شناسه اختصاصی (مانند `USER-1001`) اختصاص می‌یابد. کاربران می‌توانند بدون افشای آی‌دی تلگرام، پیام مستقیم ناشناس برای شناسه مورد نظر ارسال کنند.

- 📜 **تاریخچه هم‌صحبت‌ها و چت مجدد (`/history`):**
  مشاهده لیست افراد قبلی که با آن‌ها گفتگو داشته‌اید و ارسال آسان درخواست اتصال مجدد با زدن یک دکمه.

- 🚨 **سیستم گزارش تخلف و مسدودسازی خودکار (Report & Auto-Ban):**
  امکان قطع فوری مکالمه و ثبت گزارش تخلف با کلیک روی دکمه `[🚨 گزارش تخلف]` یا دستور `/report`. اگر کاربری در ۲۴ ساعت ۳ گزارش دریافت کند، سیستم به صورت خودکار دسترسی او را در دیتابیس و ردیس مسدود (Banned) می‌کند.

- 🛡️ **پنل مدیریت جامع ادمین (`/admin`):**
  - داشبورد آماری لحظه‌ای (کاربران کل، صف ردیس، مکالمات زنده، سکه‌های در گردش).
  - کنسول بررسی گزارش‌های تخلف با متن پیام‌های اخیر جهت قضاوت منصفانه.
  - **سیستم ارسال بنر تصویری و پیام همگانی (Safe Chunked Broadcast):** ارسال پیام یا بنر تصویری در دسته‌های ۲۵تایی در ثانیه همراه با گزارش دقیق ارسال موفق و ناموفق (کاربران بلاک‌کننده).

- ⚡ **سپر ضداسپم (Rate Limiting via Redis):**
  جلوگیری از ارسال رگباری پیام (حداکثر ۵ پیام در ۳ ثانیه) و جستجوی مکرر (حداقل فاصله ۵ ثانیه).

## 🚀 راهنمای نصب و راه‌اندازی گام‌به‌گام (ویژه کاربران مبتدی)

اگر تا کنون ربات تلگرام یا سرور راه‌اندازی نکرده‌اید، اصلاً نگران نباشید! مراحل زیر را به ترتیب دنبال کنید:

### گام ۱: دریافت توکن ربات از BotFather در تلگرام

1. در پیام‌رسان تلگرام، آیدی **[@BotFather](https://t.me/BotFather)** را جستجو کرده و وارد چت آن شوید.
2. دستور `/newbot` را ارسال کنید.
3. یک **نام نمایشی** برای ربات خود انتخاب کنید (مثلاً: `چت ناشناس ایران`).
4. یک **نام کاربری (Username)** انگلیسی برای ربات بفرستید که در انتهای آن کلمه `bot` باشد (مثلاً: `iran_match_chat_bot`).
5. تبریک! ربات‌پدر به شما یک توکن طولانی شبیه به کد زیر می‌دهد:
   ```text
   7123456789:AAFlmNpQrStUvWxYz123456789abcdefghi
   ```
   این توکن را کپی کرده و در جایی یادداشت کنید.

---

### گام ۲: دریافت پایگاه‌داده رایگان (PostgreSQL و Redis)

> 💡 **نکته هوشمند:** ربات دارای پایگاه‌داده و حافظه کش پیش‌فرض حافظه‌ای (In-Memory) است، بنابراین حتی بدون دیتابیس خارجی نیز فوراً کار می‌کند. اما برای ذخیره دائمی اطلاعات، راه‌اندازی دیتابیس بسیار آسان است.

#### گزینه الف) استفاده از سرویس‌های رایگان ابری (بدون نیاز به نصب روی سرور):
- **پایگاه‌داده PostgreSQL رایگان:** در سایت [Neon.tech](https://neon.tech) یا [Supabase.com](https://supabase.com) در کمتر از ۱ دقیقه ثبت‌نام کنید و لینک اتصال (`DATABASE_URL`) را کپی کنید.
- **حافظه Redis رایگان:** در سایت [Upstash.com](https://upstash.com) یک دیتابیس رایگان بسازید و لینک اتصال (`REDIS_URL`) را دریافت کنید.

#### گزینه ب) نصب محلی با داکر (اگر سرور اختصاصی/VPS دارید):
```bash
# اجرای PostgreSQL
docker run --name postgres-bot -e POSTGRES_PASSWORD=mysecretpassword -p 5432:5432 -d postgres:15

# اجرای Redis
docker run --name redis-bot -p 6379:6379 -d redis:alpine
```

---

### گام ۳: دانلود پروژه و پیکربندی متغیرهای محیطی (`.env`)

1. وارد پوشه پروژه در ترمینال یا سرور خود شوید:
   ```bash
   cd telegram-matchmaking-bot
   ```

2. فایل نمونه تنظیمات را کپی کنید تا فایل اصلی `.env` ساخته شود:
   ```bash
   cp .env.example .env
   ```

3. فایل `.env` را با یک ویرایشگر باز کنید (مثلاً در لینوکس: `nano .env` یا در ویندوز با Notepad):
   ```bash
   nano .env
   ```

4. مقادیر را مطابق راهنمای زیر تکمیل کنید:
   ```env
   # ۱. توکن دریافت شده از BotFather (الزامی)
   TELEGRAM_BOT_TOKEN="7123456789:AAFlmNpQrStUvWxYz123456789abcdefghi"

   # ۲. آدرس پایگاه داده PostgreSQL (در صورت تمایل به ذخیره دائمی)
   DATABASE_URL="postgresql://postgres:mysecretpassword@localhost:5432/telegram_matchmaking"

   # ۳. آدرس پایگاه داده Redis
   REDIS_URL="redis://default:myredispassword@localhost:6379"

   # ۴. آیدی عددی تلگرام مدیران ربات (با کاما جدا کنید)
   # برای دیدن آیدی خود به ربات @userinfobot در تلگرام پیام دهید
   ADMIN_TELEGRAM_IDS="123456789,987654321"

   # ۵. پورت اجرای سرور
   PORT=3000

   # ۶. حالت اجرا
   NODE_ENV="production"
   ```
   برای ذخیره فایل در `nano`، کلیدهای `Ctrl + O` و سپس `Enter` را بزنید و با `Ctrl + X` خارج شوید.

### گام ۵: ایجاد ساختار جداول دیتابیس (Migrations)

برای ایجاد خودکار جدول‌های کاربران، تراکنش‌های سکه، فیلترها و گزارش‌های تخلف در PostgreSQL، دستور زیر را اجرا کنید:

```bash
npm run db:push
```
سیستم با اتصال به دیتابیس، تمامی مدل‌ها را در کسری از ثانیه همگام‌سازی می‌کند.

---

### گام ۶: اجرای ۲۴ ساعته ربات با PM2 (اجرای دائم در پس‌زمینه)

برای اینکه ربات حتی پس از بستن ترمینال یا ری‌استارت سرور همیشه آنلاین و پاسخگو بماند، از ابزار استاندارد **PM2** استفاده می‌کنیم:

1. **نصب PM2 به صورت سراسری:**
   ```bash
   npm install -g pm2
   ```

2. **بیلد پروژه (کامپایل TypeScript و فرانت‌اند):**
   ```bash
   npm run build
   ```

3. **روشن کردن ربات:**
   ```bash
   pm2 start server.ts --name "telegram-matchmaking-bot" --interpreter tsx
   ```

4. **تنظیم روشن‌شدن خودکار در زمان ریبوت سرور:**
   ```bash
   pm2 save
   pm2 startup
   ```

#### 📌 دستورات مفید مدیریت ربات با PM2:
- **مشاهده وضعیت ربات:** `pm2 status`
- **مشاهده لاگ‌های زنده چت و درخواست‌ها:** `pm2 logs telegram-matchmaking-bot`
- **ری‌استارت کردن ربات:** `pm2 restart telegram-matchmaking-bot`
- **خاموش کردن ربات:** `pm2 stop telegram-matchmaking-bot`

## 📖 راهنمای دستورات ربات (Bot Commands Reference)

کاربران می‌توانند از دستورات زیر در محیط چت تلگرام استفاده کنند:

| دستور | عملکرد | دسترسی |
| :--- | :--- | :---: |
| `/start` | راه‌اندازی ربات، ثبت‌نام اولیه ۶ مرحله‌ای و بازگشت به منوی اصلی | عمومی |
| `/search` یا `/find` | شروع جستجوی هم‌صحبت جدید بر اساس فیلترهای تنظیمی | عمومی |
| `/next` | قطع چت فعلی و جستجوی بلافاصله هم‌صحبت بعدی | عمومی |
| `/stop` یا `/end` | اتمام مکالمه جاری و بازگشت به منوی کاربری | عمومی |
| `/report` | گزارش تخلف هم‌صحبت جاری و قطع فوری چت برای حفظ سلامت محیط | عمومی |
| `/profile` | نمایش کارت پروفایل ناشناس و امکان ویرایش بیو، سن، استان و عکس | عمومی |
| `/filters` | تنظیم فیلترهای جستجو (سن دلخواه، جنسیت هدف، استان همسان/خاص) | عمومی |

| `/daily` | دریافت سکه رایگان روزانه (هر ۲۴ ساعت یکبار) | عمومی |
| `/history` | تاریخچه گفتگوهای قبلی و امکان ارسال درخواست چت مجدد | عمومی |
| `/find_id USER-XXXX` | ارسال پیام مستقیم ناشناس به کاربر دیگر با داشتن شناسه داخلی | عمومی |
| `/admin` | باز کردن داشبورد مدیریت، بررسی گزارش‌ها و ارسال بنر همگانی | ویژه مدیران |
| `/help` | راهنمای کامل نحوه کارکرد ربات به همراه لیست دستورات | عمومی |

## 🛡️ عیب‌یابی و نکات مهم (Troubleshooting)

1. **خطای اتصال تلگرام در سرورهای ایران (Network / Proxy Error):**
   - APIهای تلگرام برای دسترسی به اینترنت آزاد نیاز دارند. اگر سرور شما داخل ایران قرار دارد، از پروکسی محلی یا سرور خارج کشور (VPS آلمان، هلند یا فنلاند) استفاده کنید.
2. **پیدا کردن آیدی عددی تلگرام برای ادمین:**
   - کافی است در تلگرام به ربات رسمی `@userinfobot` پیام دهید؛ آیدی عددی شما در خط اول پیام مشخص می‌شود (مثلاً `123456789`). آن را در متغیر `ADMIN_TELEGRAM_IDS` در فایل `.env` وارد کنید.
3. **ریست کردن یا بازنشانی کامل اطلاعات تست:**
   - می‌توانید از داخل داشبورد وب دکمه `Reset Database & Queues` را کلیک کنید یا دیتابیس لوکال را خالی نمایید.
